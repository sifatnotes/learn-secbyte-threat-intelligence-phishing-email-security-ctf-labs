## Learning Path

1. **Learn intelligence fundamentals:** Start with the threat intelligence primer.
2. **Investigate indicators:** Explore IP reputation, IOC detection, and validation.
3. **Study email security:** Continue with MailGuard and inbox breach response.
4. **Investigate phishing:** Practice phishing trace analysis and user-reported case investigation.
5. **Build triage skills:** Explore email trails, campaign hunting, and gateway triage.

Follow the prerequisites and recommended sequence provided on each official lab page.

## How to Use the Labs

1. Open a lab using its direct link.
2. Review its objectives, requirements, and instructions.
3. Complete the exercise in the authorized training environment.
4. Document indicators, evidence, and investigation findings.
5. Summarize lessons learned and relevant defensive measures.
